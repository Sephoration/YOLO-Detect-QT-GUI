# Something Qt

一个 Qt 学习与练手的项目集合，包含多个小示例和一个相对完整的计算机视觉应用。

## 项目列表

| 项目 | 说明 |
|------|------|
| **YOLO-Viewer** | Python 版（PySide6 + Ultralytics YOLO），支持目标检测、分类、姿态估计、分割 |
| **YOLO-Viewer-C++** | C++ 版（Qt6 + OpenCV + YOLO），同样支持多任务检测，通过 Python 后端通信 |
| **5_signalAndSlot** | Qt 信号与槽基础示例 |
| **SignalAndSlot** | 信号与槽机制演示 |
| **CustomSignalAndSlot** | 自定义信号与槽示例 |
| **layoutdemo** | Qt 布局管理器演示 |
| **QWidgetDemo** | QWidget 基础控件演示 |
| **car_hmi / car_hmi_prototype** | 车载 HMI 界面原型 |
| **MusicPlayer** | 简易音乐播放器 |

## 环境

- Qt 5/6（C++ 项目）
- PySide6 + Ultralytics YOLO（Python 项目）
- OpenCV（YOLO-Viewer-C++）
