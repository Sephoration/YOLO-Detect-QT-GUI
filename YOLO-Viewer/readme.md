# 🎯 YOLO-Viewer

基于 PySide6 和 Ultralytics YOLO 的跨平台计算机视觉应用程序。提供图像分类、目标检测、姿态估计和分割检测等多种计算机视觉任务的统一处理界面。

## ✨ 功能特性

### 🔍 核心功能
- **多任务支持**: 目标检测、图像分类、关键点检测（姿态估计）、分割检测
- **多源输入**: 支持图片、视频文件、摄像头实时流、批量图片文件夹
- **实时处理**: 流畅的视频流处理，支持播放控制和进度跳转
- **智能模型识别**: 自动检测 YOLO 模型类型并配置相应处理模式
- **参数实时调整**: 支持 IOU 阈值、置信度阈值、延迟时间等参数动态调整
- **结果可视化**: 检测结果实时叠加显示在图像上，支持中文字体渲染

### 🎨 用户界面
- **双面板设计**: 左侧显示区 + 右侧控制面板
- **播放控制**: 视频播放/暂停、进度条拖动、时间显示
- **统计信息**: 实时显示检测数量、置信度、推理时间、FPS 等
- **模型管理**: 模型信息显示、参数配置、推理控制
- **批量处理**: 支持图片文件夹批量检测

## 🏗️ 系统架构

### 模块化三分离架构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   window_ui     │    │ logic_controller│    │  yolo_analyzer  │
│ (UI + 播放)     │◄──►│  (逻辑协调)     │◄──►│ (统一推理引擎)  │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │
         ▼                       ▼
┌─────────────────┐    ┌─────────────────┐
│ frame_grabber   │    │  baseDetect     │
│ (帧抓取器)      │    │ (基础类)        │
└─────────────────┘    └─────────────────┘
```

### 核心组件
- **window_ui.py**: 用户界面层，包含显示面板和控制面板
- **logic_controller.py**: 逻辑协调层，主控制器和播放器
- **yolo_analyzer.py**: 推理引擎层，统一 YOLO 处理器
- **frame_grabber.py**: 数据抓取层，按需抓取视频帧
- **baseDetect.py**: 基础类，提供通用功能

## 💻 技术栈

- **PySide6**: 跨平台 GUI 框架
- **Ultralytics YOLO**: YOLO 实现

## 🎮 使用指南

### 1. 加载模型
- 点击工具栏"加载模型"按钮
- 选择 YOLO 模型文件 (.pt)
- 系统自动识别模型类型并显示信息

### 2. 选择输入源
- **图片**: 点击"打开图片"
- **视频**: 点击"打开视频"
- **摄像头**: 点击"打开摄像头"

### 3. 配置参数
- **IOU 阈值**: 调整检测框重叠度
- **置信度**: 过滤低置信度结果
- **延迟**: 控制处理间隔

### 4. 开始检测
- 点击"开始"按钮启动推理
- 实时查看检测结果和统计信息

## 📚 支持的模型

- **目标检测**: YOLOv5, YOLOv8, YOLOv11 检测模型
- **图像分类**: YOLO 分类模型
- **姿态估计**: YOLO 关键点检测模型
- **分割检测**: YOLO 分割模型
